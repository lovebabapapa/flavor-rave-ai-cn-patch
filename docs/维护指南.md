# 维护指南（给后继汉化者）

本补丁的全部产物都可以从「译文」重新构建。目标：**任何人只改 `out/` 里的 JSON，就能产出新的补丁**。

---

## 1. 数据流

```
游戏安装目录（英文 JSON / 原始图集）
        │  pipeline.py extract
        ▼
source_files/                 原始英文快照（回填底板，勿改）
        │
        ├─► AiNiee输入/*.i18n.json        待译骨架（只含 key + 原文）
        │        │  翻译（AiNiee / 人工 / 其它模型）
        │        ▼
        └─► out/*.i18n_translated.json    ★ 译文（改这里）
                 │  pipeline.py reinject
                 ▼
        汉化输出/FR_CN_补丁/            最终覆盖包
                 │  manual_files 回填 + UI 语言表 + 汉化说明
                 ▼
              游戏目录
```

三条命令概括整个工程：

```bash
python pipeline.py extract     # 从游戏目录抽取（新增 DLC 时才需要）
python pipeline.py reinject    # 译文 → 补丁（改完译文必跑）
python build.py                # 校验 + 打包发布
```

## 2. 三种常见改动

### 2.1 改一句台词（精确修改）

1. 找到文件：文件名是路径压平而来
   `mods/Official DLC - Chillers/data/x/dreamcast.json`
   → `out/mods__Official DLC - Chillers__data__x__dreamcast.json.i18n_translated.json`
2. 结构：

   ```json
   {"dialogue": {"12": {"text": "这里是译文"}}}
   ```

   `12` 对应原文 `dialogue[12]`，`text` 是台词；结算画面用 `name` 字段。
3. 改完执行 `python pipeline.py reinject`。

> 小技巧：用 `python export_review.py` 可导出中英对照的 xlsx 核对表，改完再用脚本合并。

### 2.2 改一类术语（全局替换）

编辑 `postfix.py` 里的 `REPL` 字典（在 `# 地名统一` 附近追加即可）：

```python
"酸橙": "Sour",
"托加拉希": "唐辛子",
```

这是**最安全的批量修法**：`reinject` 时对所有译文统一执行，且在人工改译后依然生效。

### 2.3 改 UI 语言表

`menu_zh.py` 里三张表：

| 表 | 用途 | key 形式 |
|---|---|---|
| `OPTION` | 选项菜单、Modifiers | `setting_<显示名>` |
| `GAMEPLAY` | 判定、分数、结算 | `setting-<内部名>-<值>` |
| `FLAVOR` | 成就、菜单按钮、歌曲歌词 | 任意 |

Modifiers 特别注意：名称查 `setting_<显示名>`，取值查 `setting_<内部名>-<值>`（如 `setting_scrolltype-multiplicative`），两套都要补才生效。

## 3. 新增 DLC 的流程

1. 装好 DLC，确认游戏能正常启动
2. `python pipeline.py extract` —— 新文件会以 `*.i18n.json` 进入 `AiNiee输入/`
3. 翻译（可整批丢给 LLM），产物按同名放 `out/`（后缀 `_translated`）
4. `python pipeline.py reinject`
5. 若有图片类字幕，走第 4 节流程
6. `python build.py` 发布

> 注意：`extract` 只抽取 `FILE_RULES` 里登记过的路径类型，新类型需在 `pipeline.py` 里加规则。

## 4. 图片类文本（带字美术）

游戏里带字的图分两种：**sparrow atlas（多帧动画）** 和 **单张 PNG**。

### 4.1 提取

```bash
# 修改 EXTRACT 列表后运行
python - <<'PY'
# 见 汉化素材提取 脚本，或直接复用 ainiee 里的提取逻辑
PY
```

产物：`汉化素材_图片/<图集名>/帧名.png`，附原始 xml。

### 4.2 人工修图

保持**画布尺寸不变**，在图上擦掉英文、写中文，导出为 `原名_cn.png` 或放回同名文件。

### 4.3 回填

```bash
python restore_images.py        # 按 xml 坐标拼回图集，写入补丁
python restore_images.py --sync # 顺便同步到游戏目录
```

独立单图（如 `endmessage.png`）直接覆盖即可。

**尺寸不一致时**：脚本会居中贴回原始画布（宽了则等比缩放），以保持游戏里写死的贴图坐标不变。

## 5. Lua 中文字幕（图片字幕的替代方案）

图片字幕（手写体、电影片头）逐帧重绘代价过大时，用「保留原图 + 底部中文字幕」：

```lua
-- onCreate
makeLuaText('cnSub', '', 1280, 0, 620);
setTextSize('cnSub', 26);
setTextColor('cnSub', 'FFFFFF');
setTextBorder('cnSub', 2, '000000');
setTextAlignment('cnSub', 'center');
setProperty('cnSub.alpha', 0.0001);
addLuaText('cnSub');
```

关键点（都是踩过的坑）：

| 坑 | 说明 |
|---|---|
| 字体 | `makeLuaText` 默认字体 = `Language.font.get('vcr')` → `GoNotoCurrent.ttf`，**天然支持中文**，不用换字体 |
| 相机 | 过场若有 `camHUD` 被 tween 隐藏，字幕必须 `setObjectCamera('cnSub','effect')` |
| 位置 | 先确认原图文字在屏幕的位置：有的页在底部，字幕放 y=610 会被盖住，改 y=655 |
| **显隐成对** | 改 `if num == X` 块时，**不要把相邻块的 tween 一起删掉**（曾因此导致一页英文消失） |

已落地三处：`saff`（片头 8 句）、`restless`（前段 4 句）、`lodestar-shanty`（信件 6 句）。

## 6. 手工资源（manual_files）

`reinject` 会**清空重建**补丁目录，所以不走流水线的文件必须登记：

```
manual_files/          # 实际文件
manual_files.txt       # 相对路径清单，一行一个
```

`reinject` 末尾会调用 `_restore_manual()` 自动回填并打印数量。**新增这类文件后记得同时更新清单**，否则打包会缺文件（v1.0.0 之前就踩过：两个 Lua 脚本和 4 张剧情字条一度没进包）。

## 7. 发布

```bash
echo "1.0.1" > VERSION   # 改版本号
python build.py          # 校验 manual_files → 生成 zip + sha256
```

`build.py` 会：

1. 检查 `manual_files.txt` 里每个文件是否存在
2. 统计文件数 / 条目数
3. 生成 `汉化输出/FR_CN_补丁_v<版本>.zip`
4. 写出 `.sha256` 校验文件

发布页记得同步更新 `CHANGELOG.md`。

## 8. 已知坑清单（按踩坑频率排序）

| # | 坑 | 现象 | 处理 |
|---|---|---|---|
| 1 | `reinject` 清空补丁目录 | 手工文件消失 | 登记到 `manual_files.txt` |
| 2 | `FILE_RULES` 顺序 | 角色名 `synsun` 的结算文件被误判成电视百科 → 21 行漏译 | 规则「具体优先」：results 规则必须在 synsun 之前 |
| 3 | 擦除行尾空格的正则 | `\s{2,}` 会把换行吞掉，导致译文串行 | 用 `[ \t]` 不用 `\s` |
| 4 | 人名意译 | 酸酱 / 辣妹 / 酸橙 / 藏红花 / 表演大师 | 角色名永远保留英文，见 `postfix.py` 顶部规则 |
| 5 | 地名变体 | 恩辛克 / 恩兹尼克 / 恩津克 三种写法 | 统一走 `postfix.py` |
| 6 | Lua 显隐块成对 | 删掉相邻 tween 导致某页空白 | 改块前后 diff 一遍 |
| 7 | 曲名格式 | 忘了「英文（中文）」括号 | 见 `_song_titles.json` |
| 8 | Flavorpedia 计时 | 字幕 `:dur:` 标记被删 → 语音不同步 | 保留 `:dur:`/`[NL]` |

## 9. 目录约定

| 目录 | 是否入库 | 说明 |
|---|---|---|
| `out/` | ✅ | 译文，核心资产 |
| `postfix.py` / `menu_zh.py` / `pipeline.py` | ✅ | 工具与规则 |
| `manual_files/` | ✅ | 手工资源（Lua / 重绘图片） |
| `汉化底稿/` | ✅ | UI 语言表底稿 |
| `source_files/` | ⚠️ 建议不入库 | 游戏原始英文快照，属游戏数据；使用者可自行 `extract` 生成 |
| `titlecard_*` / `_user_edited.xlsx` 等 | ❌ | 中间产物 |
| `汉化输出/` | ❌ | 构建产物，发布走 Release |

> 若担心版权，仓库里只保留 `out/`（译文）+ 工具 + 手工资源；使用者用自己的游戏目录跑一次 `extract` 即可补出 `source_files/`。
