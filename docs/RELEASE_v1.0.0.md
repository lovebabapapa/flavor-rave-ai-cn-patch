## 🔧 安装

```
1. 备份游戏安装目录（整个文件夹复制一份）
2. 把补丁内所有文件按相同相对路径覆盖到游戏根目录
     assets/data/...  →  <游戏目录>/assets/data/...
     mods/<DLC名>/... →  <游戏目录>/mods/<DLC名>/...
3. 启动游戏
```

**⚠️ 新装了 DLC 之后，请重新覆盖一次补丁**，否则新 DLC 的内容会显示英文。顺序永远是：先装 DLC，再覆盖补丁。

回滚：用备份目录覆盖回去即可。

## ⚠️ 已知限制（非 bug）

| 内容 | 原因 |
|---|---|
| DLC 下载菜单仍是英文 | 列表与文案是运行时从作者服务器拉取的远程 JSON，本地无缓存，且该界面字体不含中文字形——需改源码 |
| 歌曲标题卡动画仍是英文 | 内容仅为歌名艺术字，属美术风格 |
| 评分字样 / 主菜单 logo / Kablooie 轮盘彩蛋 | 界面美术类，按设计不译 |
| 成就列表未解锁项显示「未知」 | 游戏刻意隐藏，非漏译 |
